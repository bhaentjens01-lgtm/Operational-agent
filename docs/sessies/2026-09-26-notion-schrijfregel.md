# Sessie 26/09/2026 — Notion-schrijfregel en werkwijze Jules

## Wat gebouwd
- `CLAUDE.md` governance-regel 7 "Notion schrijven via Atlas". Zonder akkoord (AUTO) mag een agent enkel zijn eigen werkpagina bijwerken en items toevoegen aan het register "Delegaties & overdrachten". Al het andere is SUGGEST via Atlas, met akkoord van Bart. Voor een register waarvan de agent eigenaar is, blijft zijn eigen governance gelden.
- `docs/governance/chief-of-staff.md`: Atlas is de poort voor Notion-schrijfvoorstellen, maar keurt ze nooit zelf goed.
- `.claude/agents/lifestyle-manager.md`:
  - de skill `interview-me` is verplicht bij elke boekingsvraag voor trips of events;
  - voorkeuren staan in het onderdeel "Voorkeuren" van de werkpagina;
  - de Notion-schrijfregel verwijst naar regel 7.

## Waarom
Een agent maakte zonder akkoord een nieuwe Notion-pagina aan, op een plaats die Bart niet koos. Bart besliste dat de regel voor alle agents geldt.

## Wat rest
- Documentsync: regel 7 overnemen in de Agent Operating Rules in Notion. Deze skill-/governancewijzigingen gelden pas in nieuwe sessies zodra ze op main staan.
- Uitzondering voor een register dat de agent zelf beheert: nog te bevestigen door Bart.
